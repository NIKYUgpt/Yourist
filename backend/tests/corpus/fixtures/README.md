# Фикстуры корпуса

Урезанные реальные редакции Трудового кодекса РФ с actual.pravo.gov.ru
(«Тексты правовых актов с внесенными изменениями»):

| Файл | Редакция | redid |
|---|---|---|
| `tk_2022_07_14.*` | с 14.07.2022 | 401591 |
| `tk_2026_09_01.*` | с 01.09.2026 | 492286 |

`*.html` — ответ `redtext` (только абзацы выбранных статей и заголовки их глав),
`*.toc.json` — соответствующие узлы ответа `getcontent`.

Статьи подобраны под разные случаи разбора:

- **1** — обычная статья с частями;
- **7** — утратила силу (отметка в `span.mark`);
- **56.1** — номер через надстрочный индекс (`<sup>1</sup>`);
- **58** — в оглавлении источника конец статьи ссылается на несуществующий абзац;
- **81** — части, пункты и подпункты; текст изменился между редакциями;
- **341.1-1** — номер с дефисом, есть только в редакции 2026 года.

Официальные тексты законов не являются объектами авторского права (ст. 1259 ГК РФ).
