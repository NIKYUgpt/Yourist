# Прогон 27.10.2026: сложные вопросы, до словаря терминов

Набор `evaluation/labor_hard.json` (25 вопросов: исключения, особые категории
работников, нормы, изменившиеся в 2026 году; два вопроса с собственной датой).
Только локальные модели. Повтор после добавления словаря терминов в поиск —
`../2026-10-28-labor-hard`.

## Что показал прогон

- Набор различает модели лучше базового: `yandexgpt-5-lite:8b` — 96% полностью верных
  ответов, `qwen3:8b` — 88%, `qwen2.5:7b` — 68%.
- **Ошибка поиска → уверенный неверный ответ.** На вопрос «Я генеральный директор,
  за какой срок предупредить об увольнении?» ни один способ поиска не нашёл ст. 280 ТК РФ
  (в законе — «руководитель организации», срок — один месяц). Все три модели ответили
  по общей ст. 80 — «две недели». Проверка ссылок и проверяющая модель такую ошибку
  не ловят: ответ следует из показанных источников. После добавления в поиск словаря
  «бытовое слово → термин закона» статья находится (см. повторный прогон).
- **Учёт даты.** Вопрос про испытательный срок для женщины с ребёнком двух лет задан
  дважды: на сегодня (ст. 70 с 01.09.2026 — дети до трёх лет, испытание не устанавливается)
  и на 01.08.2026 (тогда — дети до полутора лет, испытание установить можно). Поиск
  подобрал правильную редакцию в обоих случаях. `qwen3:8b` на 01.08.2026 процитировал
  «до полутора лет», отметил, что ребёнку два года, и всё равно ответил «нельзя» —
  логическая ошибка при верных источниках, задача для проверяющей модели.
