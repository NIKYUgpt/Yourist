# 28.10.2026: живой прогон через API — текст, голос, фото документа

Весь стек в Docker (api, deid, corpus), локальный режим: ответ — `yandexgpt-5-lite:8b`,
проверка — `qwen3:8b`, голос — Whisper `large-v3-turbo` (CPU), фото — `qwen2.5vl:7b`.
RTX 4060 Ti 8 ГБ. Голос — синтезированная речь (Windows, голос «Ирина»), фото — сгенерированный
приказ об увольнении. Это разбор случаев, а не статистика.

## Случаи

1. **Генеральный директор хочет уволиться** (текст, с ФИО и названием организации).
   Ответ верный: «не позднее чем за один месяц», ст. 280 ТК РФ (после словаря терминов
   в поиске). Проверяющая модель сначала забраковала верный ответ («ст. 280 — не про
   руководителя»), ответ переписывался впустую. После уточнения промпта проверяющей
   модели («генеральный директор — это руководитель организации») — `supported`.
2. **Задержка зарплаты больше 20 дней** (голос). Whisper распознал речь дословно, с
   заглавными буквами и знаками препинания (SpeechKit — без них, поэтому ФИО строчными
   буквами тоже маскируются). Ответ верный: приостановить работу можно (ч. 2 ст. 142),
   компенсация — не ниже 1/150 ключевой ставки за день (ст. 236). Проверяющие модели
   придираются к формулировкам (`partially` с error) — лишнее переписывание.
3. **Приказ об увольнении за прогул при отсутствии 3 часа** (фото). Прогул по
   подп. «а» п. 6 ч. 1 ст. 81 — отсутствие *более четырёх часов подряд*.
   - До исправления: отвечающая модель процитировала условие о четырёх часах, но
     ответила «увольнение законно»; проверяющая модель в одном запуске это поймала,
     в другом — нет (`supported`).
   - Исправление: для вопросов к документу модель отвечает по шагам — факты документа,
     условия нормы, выполнены ли условия, вывод (`DOCUMENT_STEPS` в prompts.py);
     в промпт проверяющей модели добавлена проверка применимости нормы к обстоятельствам.
   - После: «увольнение незаконно, так как продолжительность отсутствия меньше
     установленной нормой (более четырёх часов)» с первой попытки, проверка — `supported`.

## Время (первый запрос после запуска, с загрузкой моделей)

- текст — 46 с, из них ~20 с — смена моделей ответа и проверки в 8 ГБ видеопамяти
  и лишнее переписывание;
- голос — 143 с, из них 79 с — распознавание с загрузкой Whisper в контейнере;
  на хосте с загруженной моделью — 12 с на 20-секундную запись;
- фото — 87 с, из них 66 с — распознавание с загрузкой `qwen2.5vl:7b` (6 ГБ).

Вывод для конфигурации: на 8 ГБ видеопамяти перекрёстная проверка другой моделью стоит
заметного времени; на сервере с 16–24 ГБ обе модели помещаются одновременно.
