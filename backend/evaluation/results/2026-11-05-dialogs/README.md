# Диалоги: техническая проверка

05.11.2026. Один синтетический диалог из двух реплик, через HTTP API в Docker.
Это проверка интеграции и разбор ошибки, **не оценка общей точности системы**.

## Условия

- До исправления: `d02d1d7`; после: `2807068` (рабочий код на момент повторного
  прогона, коммит оформлен после проверки). Диалоговая миграция `d7a9c23b410e`.
- Windows, RTX 4060 Ti 8 ГБ; Python 3.12; Ollama на хосте.
- Все роли в local: ответ `yandexgpt-5-lite:8b`, анализ/проверка/обезличивание
  `qwen3:8b` (`think=false`), векторы `bge-m3` на CPU. Платные API не использовались.
- Дата норм 27.10.2026; существующий корпус ТК РФ: 38 редакций, 784 версии статей,
  1793 фрагмента. Синхронизация и индексация по расписанию отключены на время работы.
- Временный пользователь, синтетический телефон. Пользователь и сообщения удалены
  после каждого прогона; исходный телефон в JSON заменён меткой.

## Сценарий

1. Создать `POST /api/v1/assistant/dialogs` с датой 27.10.2026.
2. Вопрос о максимальном испытательном сроке обычного сотрудника, с тестовым телефоном.
3. Уточнение «А если я главный бухгалтер?» с тем же телефоном и `dialog_id`.
4. Получить историю: две реплики с номерами 1/2 и одной меткой `[ТЕЛЕФОН_1]`,
   исходного телефона в истории нет.
5. Удалить диалог: HTTP 204, последующее чтение 404, связанных вопросов в БД нет.

## Наблюдения

| Прогон | Реплика 1 | Реплика 2 | Проверка реплики 2 |
|---|---:|---:|---|
| До исправления | 20,70 с | 46,02 с | unsupported |
| После исправления | 22,01 с | 21,31 с | supported |

До исправления модель вернула JSON с запросом «К чему относится „а если“ в вопросе
о главном бухгалтере?». Тема испытательного срока потерялась, статья 70 не попала
в источники уточнения. Вторая модель обнаружила неподтверждённый вывод, хотя
детерминированная проверка ссылок дала `passed`. Эти два вердикта нельзя смешивать.

Исправление: уточнена инструкция переформулировки; добавлен независимый запрос
из текущего и двух предыдущих вопросов пользователя даже при корректном JSON модели.
В повторе тема сохранена, статья 70 есть в выдаче, оба ответа имеют проверку `supported`.
Сохранены [первый прогон](before.json) и [повтор](after.json), включая выдачу,
переформулировку, ответы и замечания проверяющей модели.

Это **проверка после настройки на том же случае**. Изменены два элемента, поэтому
по ней нельзя раздельно оценить вклад промпта и дополнительного запроса. Два времени
не являются бенчмарком: порядок, прогрев и нагрузка не контролировались. Юрист не
проводил независимую оценку; вердикт модели не является эталоном.
