# Реранкер: вариант, зафиксированный до оценочного прогона

05.11.2026. Проверяется ровно один вариант; параметры не подбираются по evaluation.

- Модель BAAI/bge-reranker-v2-m3, ревизия фиксируется перед скачиванием.
- CPU, float32, максимум 512 токенов пары, batch 4, без дообучения и порога score.
- Запрос — вариант history из первого эксперимента (детерминированный, не зависит
  от ошибок модели переформулировки). Выбор сделан до просмотра evaluation-результата.
- Те же сохранённые 24 кандидата, та же дата и тексты. Контроль — первые 8 исходной
  выдачи. Опыт — первые 8 после реранжирования. Реранкер не добавляет новых источников.
- Recall@8, MRR@8 и парный bootstrap по диалогам; отдельно задержка загрузки и
  предсказания. На development проверяется работоспособность, затем один evaluation.
- Набор имеет статус synthetic_unreviewed; превосходство по нему не означает
  юридическую правильность ответов. Включение по умолчанию не планируется до
  подтверждения качества и приемлемой задержки на целевом оборудовании.

В рабочем конвейере механизм должен быть отключаемым, сохранять исходную выдачу
при недоступности модели и ограничения даты/явных ссылок. Загрузка весов — отдельная
команда; обработка пользовательского вопроса не должна скачивать модель.

Источники реализации: [карточка BAAI](https://huggingface.co/BAAI/bge-reranker-v2-m3),
[документация Cross Encoder](https://sbert.net/docs/cross_encoder/usage/usage.html).
Score — величина для ранжирования, не вероятность юридической правильности.
