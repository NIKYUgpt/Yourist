# Итог аудита B0–B3 и обезличивания — 16.11.2026

По прямому поручению владельца выполнены две задачи: аудит стенда и разбор
смешения лиц при обезличивании. Независимая человеческая разметка остаётся
отложенной задачей владельца. Модельные прогоны и внешние API не запускались.

## Результат

- [Стенд B0–B3](2026-11-16-benchmark-audit.md): исправлены перекрытие бюджета
  и температуры профилем, распознавание обёрнутых HTTP-таймаутов, потеря текущей
  попытки при отмене и неполная проверка парности повторов. Добавлены атомарное
  сохранение отчёта и сводка токенов с явными неизвестными значениями.
- [Обезличивание](2026-11-16-deid-audit.md): воспроизведено смешение одноимённых
  работников. Исправлена потеря уже разделённых меток при реконструкции обратного
  индекса: новое неоднозначное упоминание не присваивается последнему участнику.
  Метаданные находки содержат `identity: ambiguous` без исходного ФИО.
- Разделение разных лиц при первом появлении одинакового ФИО остаётся открытым.
  Исходный синтетический пример по-прежнему показывает одно смешение до/после.
  Для полного решения нужен явный сигнал участника и сценарий уточнения;
  служебная отметка пока не запускает такой сценарий в основном Pipeline.


- **372 passed за 71.81 с**. Перед запуском проверено отсутствие БД с этим точным
  именем; conftest создал отдельную тестовую БД. Рабочая БД для тестов не использовалась.
- Ruff: все проверки пройдены, **178 файлов** уже соответствуют форматированию.
- `git diff --check` прошёл. Изменений файлов результатов 15.11 в diff нет.
- Изолированные прогоны 74 deid и 55 evaluation — дополнительные проверки,
  их числа не складываются с полным набором 372.
- Синтетические результаты до/после и хеши исходников сохранены отдельно в
  `backend/evaluation/results/2026-11-16-deid-audit-before/` и `...-after/`.

Проверки с подменными провайдерами доказывают свойства логики стенда, а не
юридическую точность ответов или производительность моделей. Embedding usage
остаётся неизвестным. Контрольные записи отчёта теперь входят во время случая;
это отражено в метаданных будущих запусков.

новых коммитов, push, merge и релиза в этой работе нет. Пользовательский `10`
не открывался и не менялся; резервные копии не менялись. Грамматическая коррекция
и экспериментальные механизмы не подключались к продукту.

Две выбранные задачи аудита завершены с описанными ограничениями. Следующий
технический шаг предлагается отдельно: определить контракт явных участников и
поведение уточнения при неоднозначной личности. Это предложение, не новое
поручение. Для измерения юридического качества по-прежнему нужен человеческий эталон.
