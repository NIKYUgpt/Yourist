## Точка продолжения

Передать два пакета разным разметчикам, независимо проверить случаи и нормы,
сохранить сдачи, разрешить расхождения и заморозить принятую версию данных.
Только затем запускать новую серию для оценки юридического качества и калибровки
оценщиков. Старые ответы пилотов не допускаются к формальной оценке задним числом.
Публикация, push, релиз и включение экспериментальных C/D в продукт не выполнялись.

**Финальный коммит пока не создан:** в предыдущем сеансе `git add` завершился ошибкой
`Unable to create 'A:/work/Yourist/.git/index.lock': Permission denied`.
Окружение разрешает чтение `.git`, но не запись. Файлы сохранены в рабочем дереве;
добавление в индекс не выполнено. В сеансе с правом записи остаётся выполнить:

```powershell
git diff --check
git add -- README.md docs/research-plan.md docs/progress/2026-11-15-research-a-d.md docs/progress/2026-11-16-finalization.md backend/evaluation/annotation/answers-v1/README.md 'backend/evaluation/results/2026-11-15-*'
git diff --cached --check
git commit -m "Сохранил результаты пилотов и инструкции по разметке"
```

Пользовательский `10` в эти пути не входит. Перезапуск моделей для оформления
коммита не требуется.

Obsidian в этом сеансе доступен для чтения; запись в его каталог не разрешена
окружением. Существующий `validation.json` от 15.11 содержит пустые списки
нарушений и `sqlite_integrity: ok`; это исторический результат, новая проверка
и переиндексация не выполнялись. После получения доступа на запись нужно
обновить карточку Yourist и точку продолжения этой записью, затем выполнить
`brain.py reindex` и `brain.py validate`.
