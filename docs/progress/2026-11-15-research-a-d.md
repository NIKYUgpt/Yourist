# Yourist — этапы A–D, 15.11.2026

Техническая основа A–D реализована и проверена локальными пилотами. Этапы
научной проверки целиком не закрыты: независимой человеческой разметки пока нет.
Четыре случая — просмотренный development-набор, не слепой тест.

- **A:** строгая схема, происхождение и даты случаев, пакеты для двух разметчиков,
  импорт с проверкой неизменности вопросов, согласие и журнал разногласий.
  Отсутствие нормы можно обозначить явно; машинный черновик не становится эталоном.
- **B:** B0 без источников, B1 лексический поиск, B2 гибрид без реранкера,
  B3 проверяющий и максимум одно исправление. O доступен только с принятым эталоном.
  Сохраняются все попытки, ошибки, ответы, токены и время. Есть слепой пакет оценки,
  проверка хешей и парный bootstrap по семействам после завершения оценок.
- **C:** ограниченное чтение снимка корпуса, MCP stdio, поиск предложенных
  проверяющим норм с проверкой акта и даты. Существование статьи не доказывает
  применимость. Новые механизмы остаются исследовательскими.
- **D:** локальная морфологическая коррекция только внутри меток с проверкой
  допустимых замен. Неоднозначные формы сохраняют исходную подстановку. В API
  коррекция не включена; хранение соответствий и TTL не менялись.

## Результаты и границы выводов

Первый пилот B0–B3: 16 запусков, 15 завершены с допустимым ответом; C04/B3
завершился ошибкой формата проверяющего. Этот неуспех остался в знаменателе.
Все остальные правовые оценки пока не разрешены. Доля подтверждённых успехов не
известна; интервал возможных значений 0–1 для B0/B1/B2 и 0–0.75 для B3, а не
«точность 0%». Проверяющий системы не оценивает собственное юридическое качество.

Отдельное сравнение генераторов B0/B2 на тех же четырёх случаях, по одному повтору:

| Модель | Вариант | Медиана, с | P90 попытки, с | Операционные сбои |
|---|---|---:|---:|---:|
| YandexGPT-5 Lite 8B | B0 | 3.96 | 6.77 | 0/4 |
| YandexGPT-5 Lite 8B | B2 | 6.26 | 8.75 | 0/4 |
| Qwen3 8B | B0 | 8.95 | 15.77 | 0/4 |
| Qwen3 8B | B2 | 13.06 | 15.10 | 0/4 |

Это 16 технически завершённых ответов, **не рейтинг юридической точности**.
Серии выполнялись последовательно после тестов; порядок внутри серии перемешан
с одинаковым seed. Отдельного прогрева не было; загрузка моделей учитывается в
полной задержке и серверных длительностях. Один повтор и четыре случая не дают
устойчивой оценки производительности. Платные LLM API не использовались;
электричество и амортизация не измерены, денежная стоимость = null, не ноль.

Повтор C на C01/C03 (`navigation-v2`) завершил 8/8 запусков без ошибок инструментов:

| Вариант | Медиана попытки, с | Наблюдение |
|---|---:|---|
| B2 | 6.31 | контроль |
| C-navigation | 4.76 | в обоих случаях не выбраны статьи; скорость не означает успех |
| C-hybrid | 15.57 | получены статьи поверх гибридной выдачи |
| C-missing | 38.24 | предложения норм проверены по снимку; выполнен ограниченный повтор |

Юридическая польза C не установлена. Самостоятельную навигацию в таком виде
не заменяем ею текущий поиск. MCP проверен настоящим stdio-клиентом: SDK 1.30.0,
протокол 2025-11-25, допустимые чтения и отклонение отсутствующей статьи/лимита.
Стенд B/C вызывает тот же прикладной слой напрямую: транспортные расходы MCP
в приведённые времена не входят.

D: 16 синтетических примеров, из них 15 с определённой ожидаемой формой.
Точное восстановление: исходная подстановка 1/15, коррекция 11/15; текст вне меток
сохранён в 16/16. На 12 примерах детекции: TP=13, FP=3, FN=2,
precision=0.8125, recall=0.8667. Найдено слияние разных людей с одинаковым ФИО.
Не исправляются, в частности, управление глаголом, неоднозначный предлог,
инициалы и согласование через союз. Это созданные при разработке примеры,
не независимая оценка на реальных персональных данных. Решение: оставить
коррекцию экспериментальной, не включать в основной конвейер.

## Проверки и воспроизводимость

- Полный набор до последних уточнений схемы/навигации: 334 passed, 69.87 с.
  После уточнений: 92 профильных теста passed, 1.52 с; Ruff проходит.
- Тесты использовали отдельную БД yourist_preflight_test. Корпус читался в
  REPEATABLE READ READ ONLY, рабочие данные и конфигурация не изменялись.
- Начальные ответы с ошибками JSON/повторением issue ID сохранены в smoke и
  schema-smoke. Первая свободная навигация выбирала неверные инструменты;
  C-hybrid достигал 8191/8192 входных токенов, поэтому эта серия не доказывает
  эффект навигации. В повторе компактное оглавление, раздел → до двух статей,
  проверка границы контекста и запрет собственных знаний для всех вариантов кроме B0.
- Ранние технические пилоты частично пересекались с тестами и имеют незакоммиченный
  код с записанными хешами; полного архивного снимка каждого промежуточного варианта
  нет. Финальные серии привязаны к f5d1dcc и проверены отдельным манифестом исходников.
- Снимки содержат нормы, редакции и хеши, но свежесть относительно официального
  сайта не удостоверена: портал права снова не ответил при подготовке 15.11.
  Проверку нормы и применимости должны выполнить разметчики.

Коммиты реализации: b68ddd7, 135efa3, f5d1dcc. Нового релиза и push нет.
Запущены локальные Docker DB и Ollama. Новые C/D-механизмы в продукт не включены.

`backend/evaluation/annotation/answers-v1/`. Протокол: [answers-protocol.md](../experiments/answers-protocol.md).
Все результаты — `backend/evaluation/results/2026-11-15-*`:
`answers-pilot`, `navigation-v2`, `models-yandex`, `models-qwen`, `restoration-pilot`;
неудачные `answers-smoke`, `answers-schema-smoke`, `navigation-pilot` сохранены отдельно.

Из backend, с доступной локальной БД и установленными моделями:

```powershell
.\.venv\Scripts\python.exe -m app.evaluation.answer_benchmark --dataset evaluation/answers_v1.json --out evaluation/results/new-run --variants B0 B1 B2 B3
.\.venv\Scripts\python.exe -m app.evaluation.answer_benchmark --dataset evaluation/answers_v1.json --out evaluation/results/new-navigation --variants B2 C-navigation C-hybrid C-missing --cases C01 C03
.\.venv\Scripts\python.exe -m app.evaluation.restoration_eval --dataset evaluation/restoration_v1.json --out evaluation/results/new-restoration
```

Для MCP нужна дополнительная зависимость проекта `[research]`. Результаты
не перезаписываются. Для смены генератора — `--model qwen3:8b`; внешний API
стенд не допускает. Oracle намеренно не запускался: принятого эталона нет.

**Следующий шаг:** два независимых разметчика проверяют исходные случаи, даты и
нормы; затем разрешение разногласий и новая замороженная версия данных. После
этого оценка полных ответов и калибровка оценщиков. Не переходить к выводу о
превосходстве моделей, памяти решений или дообучению на основании этих пилотов.
