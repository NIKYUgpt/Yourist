# Вход для продолжения Yourist

Сначала прочитай и выполни [AGENTS.md](AGENTS.md). Перед каждым новым заданием
обязателен `git pull --ff-only --no-autostash` текущей ветки после проверки статуса.
При неуспешной синхронизации не начинай новые правки; порядок диагностики — в AGENTS.md.

После успешного pull перечитай актуальный [HANDOFF.md](HANDOFF.md): там точка
остановки, проверки, ограничения, контракты и предложенный следующий шаг.
Затем открывай только материалы нужной задачи.

Текущий запрос владельца важнее исторических планов и отчётов. Человеческая
разметка отложена, автоматически её не начинать. Контекст для совместной работы
содержится в репозитории; личный Obsidian и приватные данные владельца не нужны.
